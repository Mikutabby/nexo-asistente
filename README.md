# 🧠 Nexo Asistente

Asistente del hogar de miku con autonomía total.

## 🚀 Instalación

```bash
curl -fsSL https://raw.githubusercontent.com/mikuyasha/nexo-asistente/main/install.sh | bash
```

## 📦 Herramientas

### Sistema de Conocimiento
- `nexo-graph` — Knowledge graph v2 con SQLite + FTS5
- `nexo-memory` — Memoria persistente
- `nexo-knowledge` — Puebla el grafo con conocimiento

### Autonomía
- `nexo-autonomy` — Sistema de autonomía total
- `nexo-autoheal` — Auto-reparación de problemas
- `nexo-reasoning` — Razonamiento y toma de decisiones
- `nexo-personality` — Personalidad evolutiva

### Inteligencia
- `nexo-predict` — Predicción de problemas
- `nexo-context` — Contexto profundo de miku
- `nexo-creative` — Creatividad e innovación
- `nexo-learn` — Aprendizaje automático

### Monitoreo
- `temp-monitor` — Monitoreo de temperatura
- `nexo-optimize` — Optimización continua

### Documentación
- `nexo-doc` — Documentación automática

## 🔧 Uso

### Ver salud del sistema
```bash
nexo-autonomy health
```

### Ejecutar ciclo completo
```bash
nexo-autonomy cycle
```

### Ver predicciones
```bash
nexo-predict predict
```

### Ver contexto de miku
```bash
nexo-context show
```

### Ver conexiones
```bash
nexo-connection show
```
